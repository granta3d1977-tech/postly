# Postly — AI постогенератор для Telegram

Одностраничное приложение для владельцев Telegram-каналов и SMM-специалистов. По теме и стилю оно создаёт три варианта поста через Groq API, позволяет скопировать их и хранит последние десять генераций только в `localStorage` браузера.

## Что внутри

- Next.js 14 и App Router;
- Tailwind CSS, адаптивный интерфейс;
- три стиля: продающий, экспертный, развлекательный;
- серверный маршрут `/api/generate`, который не раскрывает Groq API-ключ браузеру;
- три варианта поста с эмодзи и хештегами, около 500 символов;
- копирование, история из 10 записей и заглушка оплаты Boosty/Telegram Donation.

## Запуск

Нужен Node.js 18.17+ (лучше LTS 20+).

```bash
npm install
cp .env.example .env.local
```

Откройте `.env.local` и задайте ключ:

```env
GROQ_API_KEY=gsk_...
# Необязательно: модель, доступная вашему API-проекту
GROQ_MODEL=openai/gpt-oss-20b
```

Запустите проект:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Для production-проверки:

```bash
npm run build
npm start
```

## Настройка оплаты

Сейчас кнопка «Поддержать» — безопасная UI-заглушка. Для реального приёма оплаты замените её обработчик в `app/page.tsx` на ссылку Boosty/Telegram Donation или вызов собственного серверного endpoint. Не размещайте секреты платёжных систем в клиентском коде.

## Важно

`.env.local` уже исключён из Git. Не публикуйте API-ключ и не задавайте `NEXT_PUBLIC_GROQ_API_KEY`: всё обращение к Groq должно оставаться в `app/api/generate/route.ts`.

## Лимиты Groq

У Groq есть лимиты на запросы и токены, которые зависят от выбранной модели и аккаунта. Проверяйте доступный лимит и список моделей в [Groq Console](https://console.groq.com/).
